## 🙋 FAQ

- Q: **_"What file formats are available?"_**\
  A: Currently, the available file formats are `ASE`, `ASEPRITE`, `PNG`, and `SVG`.

1. Download the flags in your flavor of your choice.
2. Enjoy!
